กดค้างแล้วพูด ปล่อยเพื่อส่งคำถาม

กดปุ่มกลางค้างแล้วพูดด้วยภาษาที่เลือก ไทยหรืออังกฤษ แอปถ่ายภาพพร้อมรับเสียง ปล่อยเพื่อส่ง แล้วอ่านและฟังคำตอบเมื่อประมวลผลเสร็จ

  • ถามเกี่ยวกับสิ่งของ สี และรายละเอียดที่มองเห็น
  • ถามต่อในภาพเดิมผ่านเครื่องมือทดสอบ โดยเก็บบริบทข้อความล่าสุดแบบใช้หน่วยความจำน้อย
  • คำตอบเริ่มต้นเป็นภาษาไทย ขอให้ตอบภาษาอังกฤษได้
อ่านคำตอบออกเสียงอัตโนมัติด้วยเสียง Apple ที่มีในเครื่อง ปิดหรือเลือกเสียงได้ในตั้งค่า
ข้อความที่อยู่รอบตัว

อ่านข้อความ ทีละสิ่งที่คุณสนใจ

อ่านป้าย เมนู ฉลาก หรือเอกสารด้วย OCR บนเครื่อง เลือกกรอบหรือกลุ่มข้อความ เพื่ออ่านและสรุปเฉพาะส่วนที่ต้องการ

  • แยกข้อความตามป้าย เมนู และฉลาก
  • ดูข้อความ OCR ต้นฉบับประกอบกับสรุป
  • เลือกกรอบเล็กลงเมื่อข้อความแน่นหรือยาวเกินไป
ตัวเล็ก ภาพเอียง และลายมืออาจอ่านผิด ควรตรวจข้อความต้นฉบับ
รู้ที่มาของระยะที่ได้รับ

สำรวจระยะ รู้ที่มาของคำตอบ

ถามถึงวัตถุในภาพใหม่ LiDAR ใช้ความลึกจากเซ็นเซอร์ ส่วนเครื่องไม่มี LiDAR จะให้ DA3 ประมาณระยะด้วยข้อมูลเลนส์เมื่อถามระยะหรือเปิดเลือกจุดเท่านั้น

  • เก็บภาพคู่กับข้อมูลกล้องของการถ่ายครั้งนั้น
  • แยกค่าประมาณ DA3 ชัดเจนและปัดเป็น 0.1 เมตร
  • เมื่อไม่มี depth ที่ใช้ได้หรือข้อมูลเลนส์ที่จำเป็น ระบบไม่ให้ตัวเลขระยะ
ค่า DA3 เป็นค่าประมาณ เทียบสเกลแยกตามกล้องได้ ยังไม่ได้ยืนยันกับระยะอ้างอิงจริงบน iPhone ส่วนภาพนำเข้าที่ไม่มีคู่ depth จะไม่ให้ระยะเป็นตัวเลข
จากภาพตรงหน้า สู่ความเข้าใจ

กดค้างแล้วพูด ปล่อยปุ่มเพื่อส่ง

แต่ละคำถามถ่ายภาพใหม่พร้อมรับเสียง ปล่อยปุ่มเพื่อส่ง ความเงียบระหว่างกดค้างไม่ทำให้ส่งเอง

  1. 01

    กดค้างแล้วพูด

    กดปุ่มกลางค้างเพื่อถ่ายภาพและรับเสียงพร้อมกัน พูดขณะถือปุ่มได้ ครั้งแรกต้องอนุญาตกล้องและไมโครโฟน

  2. 02

    ปล่อยเพื่อส่ง

    ปล่อยปุ่มเพื่อหยุดเสียงและส่งเมื่อภาพพร้อม รับเสียงได้ไม่เกิน 2 นาที หากยาวเกินกำหนด ระบบจะแจ้งให้พูดสั้นลง

  3. 03

    ประมวลผลในเครื่อง

    Apple Dictation ถอดเสียงตามภาษาที่เลือกก่อน Qwen ตอบจากภาพ มีสถานะขั้นตอน และใช้ปุ่มเดิมเพื่อยกเลิกระหว่างทำงาน

  4. 04

    อ่านและฟังคำตอบ

    ดูคำถามกับคำตอบบนหน้าจอ พร้อมเสียง Apple อ่านคำตอบที่เสร็จแล้ว เลือกเสียง อ่าน OCR หรือเลือกพื้นที่เพิ่มเติมได้ในตั้งค่า

คำถามที่อาจสงสัย

ดาวน์โหลด LunaV จาก App Store ได้หรือยัง?

LunaV ยังเป็นแอปต้นแบบงานวิจัย เว็บไซต์นี้ยังไม่มีรุ่น App Store ให้ดาวน์โหลด ไปที่ GitHub ของโปรเจกต์เพื่อดูโค้ดเว็บไซต์และข้อมูลโครงการ โดย repo นี้ยังไม่รวมซอร์สแอป iPhone หรือน้ำหนักโมเดล

ดูโปรเจกต์บน GitHub
เปลี่ยนภาษาหน้าจอแอปได้ไหม?

ได้ ที่ตั้งค่า → ภาษาแอพ เลือกไทยหรือ English หน้าจอเปลี่ยนทันทีและจำค่าหลังเปิดแอปใหม่ โดยเปลี่ยนเฉพาะข้อความหน้าจอ ภาษารับเสียง ภาษาคำตอบ เสียงอ่าน และคำถาม คำตอบ หรือ OCR เดิมยังคงเดิม ส่วนหน้าต่างระบบ iOS ใช้ภาษาตามการตั้งค่าของระบบ

ดูเวอร์ชันแอปได้ที่ไหน?

ถามด้วยเสียงแบบออฟไลน์ได้ไหม?

ได้ เมื่อมีภาษา Apple Dictation ที่เลือกติดตั้งแล้ว ค่าเริ่มต้นเป็นไทย เปลี่ยนเป็น English ได้ในตั้งค่า ภาษาที่ยังไม่มีอาจดาวน์โหลดจาก Apple ระหว่างเตรียม ส่วนการถอดคำถามทำบนเครื่องและไม่ได้สลับภาษาให้อัตโนมัติ

LunaV พูดคำตอบออกเสียงหรือไม่?

อ่านคำตอบ AI, OCR, สรุป และระยะออกเสียงอัตโนมัติเมื่อเสร็จ ใช้เสียง Apple ที่มีในเครื่อง เลือกเสียงไทย/อังกฤษหรือปิดได้ในตั้งค่า เมื่อเริ่มถ่ายใหม่เสียงจะหยุด เสียงที่ API นี้รองรับไม่ใช่ Siri

ทำไมบางคำถามใช้เวลาประมวลผล?

เครื่องหน่วยความจำจำกัดคืนโมเดลเมื่อว่าง เพื่อให้มี RAM ระหว่างคำถามมากขึ้น การโหลดใหม่อาจเพิ่มเวลารอ โดยคงโมเดลและความละเอียดภาพเดิม แอปแสดงสถานะและยกเลิกได้ หากเสียงไม่พร้อม ยังพิมพ์ถามและใช้ OCR ได้เมื่อโมเดลภาพพร้อม

ต้องมี LiDAR จึงจะใช้ได้หรือไม่?

ไม่จำเป็น เครื่องไม่มี LiDAR ที่รองรับโมเดลใช้ DA3METRIC-LARGE เมื่อถามระยะหรือเปิดเลือกจุด โดยใช้ภาพและข้อมูลเลนส์ที่เก็บไว้ ถามต่อใช้แผนที่เดิม กล้อง LiDAR ที่รองรับใช้เซ็นเซอร์ ค่าประมาณไม่ใช่ค่าที่เซ็นเซอร์วัด และภาพนำเข้าไม่มีคู่ depth จะไม่ให้ตัวเลขระยะ

เทียบสเกลระยะ DA3 ได้ไหม?

ในตั้งค่า กรอกระยะจริง 0.3–8 เมตรของพื้นผิวทึบกลางภาพ ระบบบันทึกสเกลแยกตามกล้อง ช่วยลดความคลาดเคลื่อนเชิงระบบได้ แต่ไม่ได้ทำให้ทุกฉากแม่นยำหรือรับรองว่าแม่นเท่า LiDAR

ใช้เป็นระบบนำทางขณะเดินได้ไหม?

LunaV ตอบจากภาพที่ถ่ายไว้ ทั้งระยะ LiDAR และค่าประมาณ DA3 อ้างอิงตอนถ่าย ไม่ได้เปลี่ยนตามการเดิน แอปยังไม่ใช่ระบบนำทางต่อเนื่องหรือสิ่งทดแทนอุปกรณ์ช่วยเดินทาง

นำไปใช้เชิงพาณิชย์ได้หรือไม่?

AGPL อนุญาตให้ใช้เชิงพาณิชย์เมื่อปฏิบัติตามเงื่อนไข หากต้องการสิทธิ์เพิ่มเติม สามารถสอบถามข้อตกลง commercial license แยกต่างหาก โมเดลและ dependency บุคคลที่สามยังใช้ไลเซนส์ของเจ้าของเดิม
