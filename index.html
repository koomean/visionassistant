ภาพหนึ่งใบ บทสนทนาหนึ่งเรื่อง

กดค้าง ถาม แล้วเข้าใจได้มากขึ้น

กดชัตเตอร์ค้างเพื่อถ่ายภาพใหม่ แล้วพูดคำถามเป็นภาษาไทยหรืออังกฤษ ดูข้อความที่ถอดเสียงและคำตอบของ LunaV ได้บนหน้าจอเดียวกัน

  • ถามเกี่ยวกับสิ่งของ สี และรายละเอียดที่มองเห็น
  • ถามต่อจากภาพเดิมได้ผ่านเครื่องมือทดสอบ
  • คำตอบเริ่มต้นเป็นภาษาไทย ขอให้ตอบภาษาอังกฤษได้
รุ่นปัจจุบันแสดงคำตอบเป็นข้อความบนหน้าจอ
ข้อความที่อยู่รอบตัว

อ่านข้อความ ทีละสิ่งที่คุณสนใจ

อ่านป้าย เมนู ฉลาก หรือเอกสารด้วย OCR บนเครื่อง เลือกกรอบหรือกลุ่มข้อความ เพื่ออ่านและสรุปเฉพาะส่วนที่ต้องการ

  • แยกข้อความตามป้าย เมนู และฉลาก
  • ดูข้อความ OCR ต้นฉบับประกอบกับสรุป
  • เลือกกรอบเล็กลงเมื่อข้อความแน่นหรือยาวเกินไป
ตัวเล็ก ภาพเอียง และลายมืออาจอ่านผิด ควรตรวจข้อความต้นฉบับ
ระยะที่อ้างอิงข้อมูลเซ็นเซอร์

ถามระยะ จากภาพที่เพิ่งถ่าย

เมื่อใช้กล้องหลังที่รองรับ LiDAR แอปจะเก็บภาพพร้อมข้อมูลความลึก ถามถึงวัตถุที่ระบุชัดเจน เพื่อวัดจากกล้องถึงจุดบนพื้นผิวของสิ่งนั้น

  • ใช้ภาพใหม่ที่ถ่ายในแอปและ depth ที่จับคู่กัน
  • แสดงวัตถุและจุดที่ใช้วัดระยะ
  • เมื่อไม่มี depth ที่เชื่อถือได้ ระบบจะไม่เดาระยะเป็นเมตร
เป็นระยะ ณ ตอนถ่ายภาพ ภาพนำเข้าหรืออุปกรณ์ไม่มี LiDAR ไม่ให้ค่าระยะจากเซ็นเซอร์
จากภาพตรงหน้า สู่ความเข้าใจ

เริ่มง่าย ๆ แค่กดค้างแล้วถาม

คำถามเสียงแต่ละครั้งเริ่มด้วยภาพใหม่ และประมวลผลต่อบน iPhone ของคุณ

  1. 01

    ถ่ายภาพ

    กดชัตเตอร์ค้างประมาณ 0.35 วินาที แอปเก็บภาพและ depth ที่มี ก่อนเปิดไมโครโฟน

  2. 02

    พูดคำถาม

    พูดหลังสัญญาณพร้อม เว้นเสียงประมาณ 2 วินาทีเพื่อส่ง หรือแตะชัตเตอร์เพื่อจบคำถาม

  3. 03

    ประมวลผลในเครื่อง

    Whisper ถอดเสียง แล้ว Qwen วิเคราะห์ภาพกับคำถาม โดยไม่เรียกบริการ AI บนคลาวด์

  4. 04

    ดูคำตอบ

    ดูคำถามกับคำตอบบนหน้าจอ เปิดตั้งค่าเมื่อต้องการเลือกพื้นที่ อ่านข้อความ หรือใช้เครื่องมือทดสอบ

คำถามที่อาจสงสัย

ดาวน์โหลด LunaV จาก App Store ได้หรือยัง?

LunaV ยังเป็นแอปต้นแบบงานวิจัย เว็บไซต์นี้ยังไม่มีรุ่น App Store ให้ดาวน์โหลด ติดต่อผู้ดูแลผ่าน GitHub เพื่อสอบถามซอร์สของแอป ส่วน GitHub repo นี้เก็บโค้ดเว็บไซต์

สอบถามผ่าน GitHub
LunaV พูดคำตอบออกเสียงหรือไม่?

รุ่นปัจจุบันรับคำถามด้วยเสียง และแสดงข้อความที่ถอดเสียงพร้อมคำตอบบนหน้าจอ ยังไม่มีการอ่านคำตอบออกเสียง เสียงบอกทิศทาง หรือการเตือนสิ่งกีดขวางต่อเนื่อง

ต้องมี LiDAR จึงจะใช้ได้หรือไม่?

การถามจากภาพและอ่านข้อความใช้ได้โดยไม่ต้องมี LiDAR เมื่ออุปกรณ์รองรับการรันโมเดล ส่วนการวัดระยะจากเซ็นเซอร์ต้องใช้กล้องหลัง LiDAR ที่รองรับและถ่ายภาพใหม่ในแอป ภาพนำเข้าไม่มีระยะจากเซ็นเซอร์

ใช้เป็นระบบนำทางขณะเดินได้ไหม?

LunaV ตอบคำถามจากภาพที่ถ่ายไว้ ระยะ LiDAR เป็นค่าขณะถ่ายและไม่ได้เปลี่ยนตามการเดิน แอปจึงยังไม่ใช่ระบบนำทางต่อเนื่องหรือสิ่งทดแทนอุปกรณ์ช่วยเดินทาง

นำไปใช้เชิงพาณิชย์ได้หรือไม่?

AGPL อนุญาตให้ใช้เชิงพาณิชย์เมื่อปฏิบัติตามเงื่อนไข หากต้องการสิทธิ์เพิ่มเติม สามารถสอบถามข้อตกลง commercial license แยกต่างหาก โมเดลและ dependency บุคคลที่สามยังใช้ไลเซนส์ของเจ้าของเดิม
