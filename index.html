LunaV ทำอะไรได้บ้าง?

ถามถึงสิ่งที่อยู่ในภาพ

ลองถามว่า “เสื้อตัวนี้สีอะไร” หรือ “กุญแจอยู่ตรงไหน” แอปบอกลักษณะของสิ่งของและตำแหน่งในภาพได้

  • ถ้าต้องการถามต่อจากภาพเดิม ให้เปิด “ใช้ภาพเดิมเมื่อกดค้าง” ในตั้งค่า แตะปุ่มสั้น ๆ เพื่อถ่ายภาพใหม่
  • แอปตอบเป็นภาษาไทยตามค่าเริ่มต้น ขอให้ตอบภาษาอังกฤษได้

อ่านป้าย เมนู หรือฉลาก

แอปอ่านได้ทั้งภาพ หรืออ่านเฉพาะส่วนที่คุณเลือก

  • ขอให้อ่านหัวข้อหลัก หรือระบุตำแหน่ง เช่น ด้านบนหรือด้านขวาของภาพ
  • ดูข้อความที่แอปอ่านได้ควบคู่กับสรุป
ตัวหนังสือขนาดเล็ก ข้อความเอียง และลายมืออาจอ่านผิด เทียบกับภาพต้นฉบับได้

สิ่งนั้นอยู่ห่างแค่ไหน?

ถามระยะถึงสิ่งของในภาพที่เพิ่งถ่าย แอปบอกว่าใช้เซ็นเซอร์ LiDAR หรือประมาณจากภาพ

  • คำตอบคือระยะ ณ ตอนที่ถ่ายภาพ
  • แอปบอกระยะเป็นตัวเลขเมื่อมีข้อมูลจากการถ่ายเพียงพอ
ดูว่า iPhone ของคุณรองรับการดูระยะแบบไหน
วิธีถามจากภาพ

กดค้างแล้วพูด ปล่อยปุ่มเพื่อส่ง

ก่อนถามครั้งแรก ให้อนุญาตใช้กล้องและไมโครโฟน

  1. 01

    ถ่ายภาพพร้อมพูด

    กดปุ่มกลางค้างไว้ขณะพูด แอปจะถ่ายภาพพร้อมบันทึกเสียง

  2. 02

    ส่งคำถาม

    ปล่อยปุ่มเพื่อส่งเมื่อภาพพร้อม พูดได้นานไม่เกิน 2 นาที

  3. 03

    ดูความคืบหน้า

    แอปแสดงว่ากำลังแปลงเสียงเป็นข้อความหรือเตรียมคำตอบ แตะปุ่มเดิมเพื่อยกเลิกได้

  4. 04

    อ่านและฟังคำตอบ

    คำถามและคำตอบแสดงคู่กันบนหน้าจอ ตามค่าเริ่มต้นแอปจะอ่านคำตอบให้ฟัง

คำถามที่พบบ่อย

ดาวน์โหลด LunaV จาก App Store ได้หรือยัง?

ตอนนี้เผยแพร่ซอร์สโค้ดผ่าน GitHub Releases หากต้องการติดตั้ง ให้เตรียมโมเดลและสร้างแอปด้วย Xcode

ดูซอร์สรุ่น 3.2.1
เปลี่ยนภาษาหน้าจอแอปได้ไหม?

ไปที่ ตั้งค่า → ภาษาแอพ แล้วเลือกไทยหรือ English แอปจะจำภาษาที่เลือก ส่วนภาษารับเสียงและเสียงอ่านตั้งค่าแยกได้

ดูตัวอย่างตั้งค่าภาษาอังกฤษ
ดูเวอร์ชันแอปได้ที่ไหน?

ไปที่ ตั้งค่า → เกี่ยวกับ → เกี่ยวกับ LunaV เพื่อดูเวอร์ชันที่ติดตั้งบนเครื่อง

ดูตัวอย่างหน้าเกี่ยวกับภาษาไทยจาก 3.0.0

ดูตัวอย่างหน้าเกี่ยวกับภาษาอังกฤษจาก 3.0.0

เปลี่ยนเสียงอ่านได้อย่างไร?

เลือกเสียงอ่านภาษาไทยหรืออังกฤษของ Apple ในตั้งค่า หรือปิดการอ่านอัตโนมัติได้

ทำไมบางคำถามใช้เวลาประมวลผล?

เครื่องที่มีหน่วยความจำน้อยอาจต้องโหลดโมเดลใหม่ระหว่างคำถาม หากรับเสียงไม่ได้ ให้พิมพ์ถามเมื่อโมเดลภาพพร้อม

ปรับการประมาณระยะได้ไหม?

ถ้าเครื่องใช้ DA3 ให้ใช้ระยะที่วัดจริง 0.3–8 เมตรเพื่อปรับในตั้งค่า ความแม่นยำยังขึ้นกับฉากที่ถ่าย

ใช้เป็นระบบนำทางขณะเดินได้ไหม?

LunaV ช่วยอธิบายภาพที่ถ่ายไว้ สำหรับการเดินและนำทาง ให้ใช้เครื่องช่วยเดินทางที่ใช้อยู่
