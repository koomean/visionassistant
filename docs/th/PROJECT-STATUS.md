# สถานะโครงการ LunaV

**ตรวจหลักฐานถึงวันที่ 29 ตุลาคม 2026** LunaV เป็นต้นแบบวิจัยบน iPhone ที่ประมวลผลในเครื่อง แอปรุ่นล่าสุดนำอัตลักษณ์ดวงจันทร์ของเว็บมาใช้กับหน้าจอ SwiftUI จัดหน้า Settings ใหม่ และเพิ่มแอนิเมชัน LunaVision-to-LunaV แบบเนทีฟ ส่วนการประมวลผลภาพ เสียง ระยะ และหน่วยความจำยังใช้ระบบเดิม Repo นี้เก็บเว็บไซต์และประกาศสิทธิ ไม่ได้รวมแอป iPhone โปรเจกต์ Xcode ไฟล์โมเดล หรือ log ดิบของแอป [ดูโครงการบน GitHub](https://github.com/koomean/visionassistant)

## หน้าตาแอปปัจจุบัน

หน้ากล้อง ตั้งค่า บทสนทนา เลือกพื้นที่ กลุ่มข้อความ และระยะ ใช้กรมท่าเข้ม ขาวอุ่น ฟ้า/ทองอ่อน และฟอนต์ Noto Sans Thai กับ Manrope ไอคอนแอปใช้รูปจันทร์เสี้ยวและดาวจากเว็บแล้ว Settings วางภาษา การรับเสียง และเสียงอ่านคำตอบก่อนเครื่องมือทดสอบ พร้อมรายละเอียดเสียงและการเทียบระยะที่เปิดดูเพิ่มได้ หน้ากล้องยังมีสองปุ่มหลัก และนำเมนูสลับกล้องหน้า/หลังออกจาก Settings แล้ว

แอนิเมชัน SwiftUI แสดง **LunaVision → ปากกาแดงขีด “ision” → LunaV. → หัวหน้ากล้อง** ใช้เวลาประมาณ **4.22 วินาที** งานเตรียมโมเดลเริ่มพร้อมกันและทำงานต่อใต้แอนิเมชัน ถ้ายังไม่พร้อม แอปจะแสดงสถานะเตรียมหรือลองใหม่ตามจริงหลังภาพเคลื่อนไหวจบ Reduce Motion ใช้ตรานิ่งสั้น ๆ แทน และไม่เล่นซ้ำเพียงเพราะกลับจาก background ลำดับนี้ไม่ได้ใช้ WebView หรือวิดีโอ

ภาพแอปปัจจุบันบนเว็บไซต์ถ่ายจาก **iOS Simulator วันที่ 29 ตุลาคม 2026** ภาพคำตอบและกลุ่มข้อความใช้ภาพทดสอบ OCR สังเคราะห์ ภาพเหล่านี้แสดงหน้าตาแอป ไม่ใช่หลักฐานประสิทธิภาพกล้อง ไมโครโฟน โมเดลภาพ หรือระยะบนเครื่องจริง

## ถาม อ่าน และฟังคำตอบ

หลังให้สิทธิ์ไมโครโฟน กดปุ่มกลางค้างเพื่อเริ่มถ่ายภาพ/depth และบันทึกเสียงพร้อมกัน พูดระหว่างถือ แล้วปล่อยเพื่อหยุดบันทึกและส่งเมื่อภาพพร้อม ความเงียบระหว่างถือไม่ส่งเอง แตะสั้นจะถ่ายภาพอย่างเดียว เสียงที่ยาวเกิน **2 นาที** จะถูกปฏิเสธ แทนการส่งเฉพาะต้นประโยค

ใช้ **Apple DictationTranscriber ผ่าน SpeechAnalyzer** ถอดคำถามในเครื่องด้วย asset ภาษาของ Apple ที่ติดตั้งแล้ว ค่าเริ่มต้นไทย เลือก English ได้ใน Settings คำขอใช้ภาษาที่เลือกทีละภาษา ไม่สลับภาษาอัตโนมัติ แอปตรวจการรองรับของอุปกรณ์/ภาษา หากไม่มี asset อาจต้องดาวน์โหลดครั้งแรก จึงไม่รับรองว่าเพิ่งติดตั้งแล้วจะใช้เสียงออฟไลน์ได้ทันที การถอดเสียงมีเส้นตาย **45 วินาที** และไม่มี Whisper ใน bundle แอปปัจจุบันแล้ว

อ่านคำตอบ AI/OCR/สรุป/ระยะที่เสร็จแล้วอัตโนมัติเป็นค่าเริ่มต้น ด้วย **เสียง Apple ที่ติดตั้งในเครื่อง** ปิดการอ่าน เลือกเสียงไทย/อังกฤษ และฟังตัวอย่างได้ใน Settings หยุดอ่านก่อนถ่าย/รับเสียงใหม่ ยกเลิก ล้างบริบท หรือเข้า background ไม่รับรองการใช้เสียง Siri ที่ผู้ใช้เลือกไว้ ติดตั้งเสียงเพิ่มเติมได้ผ่านการตั้งค่าของ iOS

Apple Vision OCR และ Qwen3-VL-2B-Instruct 4-bit ผ่าน MLX/Metal ทำงานในเครื่อง เครื่องมือใน Settings ใช้เลือกพื้นที่ จัดกลุ่มป้าย/เมนู/ฉลาก สรุปข้อความ OCR ที่เลือก และถามต่อด้วยบริบทที่มีขอบเขต LunaV ไม่มีการเตือนสิ่งกีดขวางต่อเนื่องหรือการบอกทิศทางนำทาง OCR การถอดเสียง ค่าประมาณ และคำตอบที่สร้างขึ้นยังผิดได้

## ระยะและแหล่งข้อมูล

บน **เครื่องที่มี LiDAR** ภาพที่รองรับใช้ depth จากเซ็นเซอร์ที่จับคู่กับภาพ เป็นระยะจากกล้องถึงพื้นผิว ณ เวลาถ่าย เครื่องกลุ่มนี้ข้าม Depth Anything 3 รวมถึงตอนข้อมูลเซ็นเซอร์ขาดหาย หาก LiDAR อ่านไม่สำเร็จจะไม่แอบแทนด้วยค่าจากโมเดลแล้วระบุว่าเป็น LiDAR

บน **เครื่องไม่มี LiDAR** ใช้ **Depth Anything 3 Metric** ที่รวมในแอปประมาณ depth จากภาพใหม่และข้อมูลโฟกัสของเลนส์ **เมื่อถามระยะหรือเลือกจุดเอง** คำถามภาพทั่วไปไม่เรียก prediction หากสำเร็จจะใช้แผนที่เดิมกับภาพเดียวกัน และลองใหม่ได้เมื่อ prediction ล้มเหลวชั่วคราว ข้อมูลเลนส์ที่ขาด ท้องฟ้า หรือค่าผิดปกติอาจทำให้ไม่มีผล คำตอบระบุแหล่งว่าเป็นโมเดลและปัดเป็น 0.1 เมตร ภาพนำเข้าที่ไม่มีคู่ depth ไม่ตอบระยะเป็นตัวเลข

Settings ปรับสเกลแยกกล้องด้วยระยะอ้างอิงจากกล้องถึงพื้นผิวใกล้กลางภาพ **0.3–8 เมตร** ได้ การเทียบสเกลอาจลดความเอนเอียงสม่ำเสมอ แต่ไม่ยืนยันฉากอื่นหรือรับรองความแม่นยำ **ยังไม่ได้เทียบ DA3 กับระยะกายภาพอ้างอิงที่วัดจริงในแอปรุ่นส่งมอบ** และข้อมูลนี้ไม่ได้รับรอง LiDAR ด้วยผลวัดกายภาพเช่นกัน

## การเตรียมและใช้ทรัพยากร

แอปกำหนด **iOS 27 / Xcode 27 ขึ้นไป** การรองรับ Dictation ขึ้นกับเครื่องและภาษา ส่วนโมเดลภาพ/depth ยังต้องมีหน่วยความจำและฮาร์ดแวร์ที่รองรับ แอปเตรียมโมเดลภาพก่อนเปิดให้ถาม และลองใหม่เมื่อเกิดปัญหาชั่วคราวขณะอยู่ foreground เตรียม DA3 เฉพาะเครื่องไม่มี LiDAR การเตรียมเสียงมีเส้นตาย **30 วินาที** และลองใหม่แยกได้ หากเสียงไม่พร้อม ยังใช้ภาพ พิมพ์ถาม OCR และสรุปได้เมื่อโมเดลที่ต้องใช้พร้อม

นโยบาย compact ใช้เมื่อ **RAM กายภาพไม่เกิน 6 GiB** หรือ process headroom ที่รายงานเป็นบวกแต่ต่ำกว่า **1 GiB** คืน weights โมเดลภาพเมื่อว่างก่อนถ่ายใหม่และหลังตอบ เก็บเฉพาะตัวอ้างอิงภาพและ cache ข้อความ/OCR/tokenizer ที่มีขอบเขต จัด OCR ก่อนโหลดโมเดลภาพที่ยังไม่อยู่ใน RAM การคืน weights ทำให้คำถามถัดไปอาจต้องรอโหลดใหม่ แยกการจำขั้น warmup ที่เสร็จแล้วออกจาก weights ที่อยู่ใน RAM เพื่อไม่ทำทุกขั้นซ้ำเมื่อกลับจาก background

การยกเลิกและการจัดการ memory warning ต้องติดตามให้งานที่กำลังใช้ทรัพยากรจบก่อนโหลดโมเดลใหม่ inference ที่ยังทำงานอาจถือ buffer จนจบ จึงไม่รับประกันคืน RAM ทันทีหรือทั้งหมด การเก็บกวาดเสียงเนทีฟไม่ขวางคำถามภาพแบบพิมพ์ งานลดทรัพยากรคง weights การ quantise ความละเอียดภาพ การตรวจคำตอบ และเกณฑ์รับงานตามหน่วยความจำเดิม การ warmup ไม่รับประกันว่า weights จะค้างใน RAM หรือทุกเครื่องรัน inference ได้

## หลักฐานก่อนหน้าและสิ่งที่ยังไม่ยืนยัน

รุ่น compact ก่อนหน้านั้นบน **iPhone 14 Pro** จบ **30/30 รอบใน 545.8 วินาที** ใช้ภาพ RGB/depth จริง ไฟล์เสียง และเปิด TTS โดย **15 รอบเป็น safe fallback หลัง retry** ไม่พบปฏิเสธเพราะ RAM หรือแอปหยุดในการรันนั้น แต่ไม่ใช่คำตอบโมเดลถูกหรืออ่านออกเสียงครบ 30 รอบ RAM หลังรอบอยู่ที่ **91.6–225.8 MiB ค่ากลาง 155.9 MiB** สูงสุดที่สุ่มวัดประมาณ **2.47 GB** RAM หลังรอบยังเพิ่มระหว่างรันและพบสถานะความร้อน serious การตรวจแบบควบคุมอีก 3 รอบเทียบ baseline ประมาณ **1.9 GiB** กับ compact **61–66 MiB** และฟื้นตัวจาก memory warning ที่ฉีดทดสอบหนึ่งครั้ง ทั้งหมดเป็นการตรวจรุ่นก่อนที่มีขอบเขต ไม่ใช่อัตราประหยัดสากลหรือรับประกันใช้ได้ไม่สิ้นสุด

งานเสียงวันที่ 24 ตุลาคมก่อนหน้านี้ผ่าน unit 224 ครั้ง ชุด UI แรกผ่าน 10/11 แล้วแก้ expectation และรันเฉพาะจุดผ่าน 2/2 ส่วน Dictation ก่อนหน้านั้นผ่าน 220/220 และ native integration อีก 6 กรณีแยกกัน ตรวจไฟล์เสียงสังเคราะห์ 5 ไฟล์และไฟล์ไม่ใช่เสียงพูด 2 ไฟล์บน iPhone 14 Pro ไฟล์ยาว 41 วินาทียังคงข้อความหลังช่วง 30 วินาที ผลประวัติเหล่านี้ไม่นำมารวมกับยอดทดสอบล่าสุด

หลักฐาน VLM/OCR บน Mac วันที่ 21 ตุลาคมมี **22 คำตอบตรง + 7 การปฏิเสธ จาก 29 กรณี** ในการปฏิเสธนั้น 6 ครั้งพลาดข้อมูลที่เห็นได้ และอีกครั้งปฏิเสธราคาที่ไม่มีในภาพ ผล Whisper สังเคราะห์เดิม **ถอดตรง 10/12** ไม่ใช่ความแม่นยำ Apple Dictation ปัจจุบัน ชุดกดค้าง/ปล่อยวันที่ 23 ตุลาคมผ่าน 155/155 ส่วน fixture ถามต่อ/LiDAR/DA3 แบบควบคุมยืนยันการเลือกเส้นทางหรือเรขาคณิตของชุดทดสอบ ไม่ใช่ความแม่นยำระยะกายภาพ

ยังไม่มีการยืนยันความแม่นยำเสียงคนผ่านไมค์ การได้ยินด้วยหู/สวิตช์ Silent และระยะเทียบการวัดกายภาพจากหลักฐานนี้ ไม่รับประกันรองรับ iPhone ทุกเครื่อง นำทางต่อเนื่อง ใช้ได้ไม่สิ้นสุด หรือคำตอบถูกทุกภาพ

## การจัดการข้อมูล

โมเดลภาพ/depth OCR การถอดเสียงด้วย asset ที่ติดตั้ง และการอ่านด้วยเสียงที่มีในเครื่อง ทำบนอุปกรณ์โดยไม่ใช้บริการ AI บนคลาวด์หรือ API key การดาวน์โหลดภาษา Apple ครั้งแรกอาจต้องใช้อินเทอร์เน็ต Qwen และ DA3 รวมอยู่ในแอป ส่วน iOS จัดการ asset เสียงและเสียงอ่าน

ไฟล์ WAV ชั่วคราว ภาพบีบอัด ภาพตัวอย่าง และภาพ crop อาจเก็บใน sandbox แอป ไฟล์เสียงลบเมื่องานที่ใช้จบจริง รวมถึงหลังยกเลิก/หมดเวลา จึงอาจไม่ลบทันทีขณะงานยังทำต่อ ภาพที่ถูกแทนจะได้รับการเก็บกวาด ไม่ได้หมายความว่าข้อมูลอยู่เฉพาะใน RAM ข้อความนี้อธิบายแอป ไม่ใช่โฮสติ้งเว็บไซต์หรือลิงก์ภายนอก

## ที่มาของหลักฐาน

ตรวจคำอธิบายกับ `README.md`, `VALIDATION.md`, ซอร์ส UI/runtime และ log ของแอปปัจจุบัน ชื่อหลักฐานเหล่านี้อ้างถึง workspace แอป ไม่ใช่ไฟล์ที่แจกใน repo เว็บไซต์นี้

หลักฐาน UI ล่าสุดใช้ `Logs/website-ui-delivery-test-summary.json`, `Logs/website-ui-source-summary.json`, `Logs/website-ui-anchor-release-build.log`, `Logs/website-ui-delivery-signature.log` และ `Logs/website-ui-device-install.log` ส่วนบันทึก session UI และภาพ Simulator ระบุการตรวจภาพหน้าจอ

ผลทรัพยากรก่อนหน้าใช้ `Logs/resource-optimization-tests-summary.json`, `Logs/resource-optimization-delivery-summary.json`, `Logs/resource-device-delivery-summary.json` และผลเครื่องจริง functional/OCR/native/TTS/normal-preparation ผล compact-memory ใช้ `Logs/memory-delivery-summary.json`, `Logs/memory-final-soak.json` และ `Logs/memory-constrained-fixed.json` ผลเสียง/เรขาคณิตก่อนหน้ายังคงที่มาชุด `answer-speech-*`, `native-dictation-*`, `da3-*`, `qa-*` และ `ptt-*`
