# เครดิตทรัพยากร

## ภาพดวงจันทร์

`assets/moon.webp` ใช้ภาพพระจันทร์เต็มดวงจาก **Moon Phase and Libration, 2021** ของ NASA (SVS 4874)

- Scientific Visualization Studio ของ NASA ให้เครดิต Ernie Wright ผู้สร้างภาพ David Ladd ผู้ผลิต และ Noah Petro ที่ปรึกษาด้านวิทยาศาสตร์
- [หน้าโครงการ](https://svs.gsfc.nasa.gov/4874/) · [ภาพต้นฉบับ](https://svs.gsfc.nasa.gov/vis/a000000/a004800/a004874/phase_full.3492.tif)
- ตัดขอบโปร่งใส ย่อจาก 3240 × 3240 เป็น 1400 × 1400 พิกเซล และบันทึกเป็น WebP โดยเก็บความโปร่งใสไว้
- เนื้อหาของ SVS เป็นสาธารณสมบัติ ยกเว้นรายการที่ระบุไว้เป็นอย่างอื่น [คำถามที่พบบ่อยของ SVS](https://svs.gsfc.nasa.gov/help/#frequently-asked-questions) · [แนวทางการใช้สื่อของ NASA](https://www.nasa.gov/nasa-brand-center/images-and-media/)

LunaV ใช้ภาพดวงจันทร์จากอดีตเพื่อประกอบเว็บไซต์ การใช้ภาพนี้ไม่ได้สื่อว่า NASA รับรองโครงการ

## ภาพตัวอย่างเมื่อแชร์

`assets/social.jpg` เป็นภาพหน้าแรกของเว็บภาษาอังกฤษ ขนาด 1200 × 630 พิกเซล ใช้ภาพดวงจันทร์ ฟอนต์ที่ให้เครดิตไว้ และงานออกแบบของเว็บไซต์

## ฟอนต์

เว็บโหลดฟอนต์ทั้งสองจากไฟล์บนเว็บไซต์ ฟอนต์แต่ละชุดใช้ SIL Open Font License 1.1

- [Manrope](https://github.com/google/fonts/tree/main/ofl/manrope) แปลงจาก `Manrope[wght].ttf` เป็น `assets/fonts/manrope.woff2` ดูเงื่อนไขได้ใน `assets/fonts/Manrope-OFL.txt`
- [Noto Sans Thai](https://github.com/google/fonts/tree/main/ofl/notosansthai) แปลงจาก `NotoSansThai[wdth,wght].ttf` เป็น `assets/fonts/noto-sans-thai.woff2` ดูเงื่อนไขได้ใน `assets/fonts/NotoSansThai-OFL.txt`

ภาพจาก NASA และฟอนต์ใช้เงื่อนไขของแต่ละแหล่ง แยกจาก AGPL ของเว็บไซต์

## แอนิเมชันเปิดหน้า

เว็บและแอปใช้สัญลักษณ์จันทร์เสี้ยวกับดาวแบบเดียวกัน เว็บไซต์สร้างตัวอักษร LunaVision และ LunaV ปากกาสีแดง (`assets/red-pen.svg`) และภาพเคลื่อนไหวที่ย้ายโลโก้ไปยังเมนูด้วย SVG, CSS และ JavaScript ส่วนแอปใช้ SwiftUI คุณเล่นแอนิเมชันเปิดเว็บซ้ำได้ และเว็บลดการเคลื่อนไหวตอนเลื่อนตามการตั้งค่าของอุปกรณ์
