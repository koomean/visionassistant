# เครดิตทรัพยากร

## ภาพดวงจันทร์

`assets/moon.webp` ดัดแปลงจากภาพนิ่งพระจันทร์เต็มดวงใน **Moon Phase and Libration, 2021** ของ Scientific Visualization Studio แห่ง NASA (SVS 4874)

- เครดิต: NASA's Scientific Visualization Studio ภาพจำลองโดย Ernie Wright ผลิตโดย David Ladd และที่ปรึกษาวิทยาศาสตร์ Noah Petro
- หน้าโครงการ: <https://svs.gsfc.nasa.gov/4874/>
- ภาพต้นฉบับ: <https://svs.gsfc.nasa.gov/vis/a000000/a004800/a004874/phase_full.3492.tif>
- การดัดแปลง: ตัดขอบโปร่งใส ปรับขนาดจาก 3240 × 3240 เป็น 1400 × 1400 พิกเซล และเข้ารหัสเป็น WebP โดยคง alpha channel ของต้นฉบับ
- SVS ระบุว่าเนื้อหาเป็นสาธารณสมบัติ เว้นแต่จะระบุไว้เป็นอย่างอื่น: <https://svs.gsfc.nasa.gov/help/#frequently-asked-questions>
- แนวทางการใช้สื่อของ NASA: <https://www.nasa.gov/nasa-brand-center/images-and-media/>

ใช้ภาพนี้เพื่อประกอบบรรยากาศดวงจันทร์ ไม่ได้แสดงว่า NASA รับรองโครงการ และไม่ได้แสดงข้างขึ้นข้างแรมแบบเวลาจริง

## ภาพตัวอย่างเมื่อแชร์

`assets/social.jpg` เป็นภาพหน้าจอส่วนเปิดเว็บภาษาอังกฤษขนาด 1200 × 630 พิกเซล ประกอบด้วยภาพดวงจันทร์และฟอนต์ที่ให้เครดิตไว้ รวมถึงงานออกแบบเว็บไซต์ต้นฉบับ ใช้เป็นภาพตัวอย่างเมื่อแชร์ ไม่ใช่ภาพหน้าจอแอป iPhone

## ภาพหน้าจอ LunaV

## ฟอนต์

ให้บริการฟอนต์จาก repository นี้ ผู้เข้าเว็บไม่จำเป็นต้องเรียกฟอนต์จาก Google Fonts หรือ CDN ฟอนต์ของบุคคลที่สาม

- **Manrope** ฟอนต์ปรับน้ำหนักได้: <https://github.com/google/fonts/tree/main/ofl/manrope> ต้นฉบับ `Manrope[wght].ttf` แปลงเป็น `assets/fonts/manrope.woff2` เก็บ SIL Open Font License 1.1 ไว้ที่ `assets/fonts/Manrope-OFL.txt`
- **Noto Sans Thai** ฟอนต์ปรับความกว้าง/น้ำหนักได้: <https://github.com/google/fonts/tree/main/ofl/notosansthai> ต้นฉบับ `NotoSansThai[wdth,wght].ttf` แปลงเป็น `assets/fonts/noto-sans-thai.woff2` เก็บ SIL Open Font License 1.1 ไว้ที่ `assets/fonts/NotoSansThai-OFL.txt`

สิทธิของภาพ NASA และฟอนต์แยกจาก AGPL ของ repository ดูเงื่อนไขที่ใช้กับแต่ละรายการได้จากไฟล์และลิงก์ต้นทางข้างต้น

## แอนิเมชันเปิดเว็บและการเคลื่อนไหวของหน้าจอ

แอนิเมชัน LunaVision-to-LunaV ใช้สัญลักษณ์จันทร์เสี้ยวและดาวเดิมของเว็บไซต์ตามที่เจ้าของโครงการเลือก รูปแบบตัวอักษร เส้นขีดปากกาแดงเป็นคลื่น `assets/red-pen.svg` และการย้ายไปที่หัวเว็บเป็นงานหน้าจอ SVG/CSS/JavaScript ต้นฉบับ

ไอคอนแอป iPhone ปัจจุบันใช้เรขาคณิตจันทร์เสี้ยวและดาวเดียวกันแล้ว แอปสร้างแอนิเมชันเปิดด้วย SwiftUI แบบเนทีฟ ส่วนเว็บไซต์ใช้ SVG/CSS/JavaScript การเคลื่อนไหวขณะเลื่อนเคารพการตั้งค่าลดการเคลื่อนไหว เล่นแอนิเมชันเปิดซ้ำได้ และไม่มีปุ่มข้ามแอนิเมชันบนหน้าจอ
