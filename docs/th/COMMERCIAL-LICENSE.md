# สิทธิการใช้งานเชิงพาณิชย์ของ LunaV

ผลงานต้นฉบับในคลังโค้ดนี้ใช้สัญญาอนุญาต [GNU Affero General Public License](../../LICENSE) รุ่น 3 หรือใหม่กว่า (`AGPL-3.0-or-later`) ใช้เชิงพาณิชย์ได้โดยไม่เสียค่าใบอนุญาตหากปฏิบัติตามเงื่อนไข AGPL

## เมื่อใดที่ต้องขอสิทธิเพิ่มเติม

หากต้องการสิทธินอกเหนือจาก AGPL ให้ติดต่อเจ้าของลิขสิทธิ์ Wachirawich Kripindakul ([koomean](https://github.com/koomean)) ข้อตกลงที่ลงนามแล้วอาจให้สิทธิเพิ่มเติมตามที่ระบุ เช่น แจกจ่ายรุ่นที่เป็นกรรมสิทธิ์โดยไม่ต้องเปิดซอร์สตามข้อกำหนดที่มีผลในกรณีปกติ

[เปิดคำถามเรื่องสิทธิเชิงพาณิชย์บน GitHub](https://github.com/koomean/visionassistant/issues/new?title=Commercial%20licence%20request%20%E2%80%94%20LunaV) อธิบายสั้น ๆ ว่าจะนำ LunaV ไปใช้อย่างไรและต้องการสิทธิอะไร คำถามบน GitHub เป็นสาธารณะ ให้ตกลงช่องทางติดต่อส่วนตัวก่อนส่งข้อมูลลับ

สิทธิเพิ่มเติมมีผลเมื่อคู่สัญญายอมรับข้อตกลงเป็นลายลักษณ์อักษรแยกต่างหาก ข้อตกลงจะระบุคู่สัญญา ผลงานที่ครอบคลุม และเงื่อนไข เช่น ราคา ระยะเวลา การสนับสนุน และการอัปเดต

## ข้อตกลงครอบคลุมอะไรได้บ้าง

- สาขาหลักเก็บไฟล์เว็บไซต์ ดาวน์โหลดซอร์ส LunaV รุ่นปกติและ LunaV Lite แยกกันได้จาก [GitHub Releases](https://github.com/koomean/visionassistant/releases) ไฟล์ของ Lite รวมโมเดล Depth Anything 3 ภายใต้สัญญาอนุญาต Apache 2.0
- สิทธิเชิงพาณิชย์ครอบคลุมเฉพาะผลงานที่เจ้าของลิขสิทธิ์มีสิทธิอนุญาต ข้อตกลงต้องระบุซอร์สแอป ทรัพยากร หรือผลงานอื่นที่ส่งมอบแยกต่างหาก
- โค้ด โมเดล และส่วนประกอบจากบุคคลที่สามใช้เงื่อนไขของเจ้าของเดิม ก่อนรับผลงานจากภายนอก โครงการควรตรวจว่าเงื่อนไขการร่วมพัฒนารองรับการให้สิทธิมากกว่าหนึ่งแบบตามที่วางไว้

หน้านี้เป็นประกาศของโครงการ การอ่านหรือส่งคำถามไม่ได้ให้สิทธิเพิ่มเติม ข้อตกลงเชิงพาณิชย์ต้องทำแยกต่างหาก และประกาศนี้ใช้แทนคำแนะนำทางกฎหมายไม่ได้
