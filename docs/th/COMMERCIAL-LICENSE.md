# การอนุญาตใช้สิทธิเชิงพาณิชย์ของ LunaV

เอกสารนี้อธิบายวิธีขอใบอนุญาตเชิงพาณิชย์แยกต่างหาก เป็นประกาศเรื่องการใช้สิทธิของโครงการ ไม่ใช่สัญญาอนุญาตใช้สิทธิเชิงพาณิชย์ฉบับสมบูรณ์

## โครงการ

- **ชื่อโครงการ:** LunaV
- **เจ้าของลิขสิทธิ์ / ผู้อนุญาต:** Wachirawich Kripindakul ([koomean](https://github.com/koomean)) เจ้าของ repository สำหรับผลงานต้นฉบับใน repository นี้
- **ช่องทางติดต่อเรื่องสิทธิเชิงพาณิชย์:** [เปิดคำถามเรื่องใบอนุญาตบน GitHub](https://github.com/koomean/visionassistant/issues/new?title=Commercial%20licence%20request%20%E2%80%94%20LunaV) Issue เป็นสาธารณะ จึงควรใส่เพียงคำถามสั้น ๆ ที่ไม่มีข้อมูลลับ โดยสามารถตกลงช่องทางติดต่อส่วนตัวกับผู้ดูแลก่อนส่งรายละเอียดที่เป็นความลับ

## ทางเลือกในการใช้สิทธิ

ผลงานต้นฉบับใน repository นี้เผยแพร่ภายใต้ GNU Affero General Public License รุ่น 3 หรือรุ่นที่ใหม่กว่าตามที่ผู้ใช้เลือก (`AGPL-3.0-or-later`) และอาจมีใบอนุญาตเชิงพาณิชย์แยกต่างหากโดยทำข้อตกลงเป็นลายลักษณ์อักษรกับเจ้าของลิขสิทธิ์

AGPL อนุญาตให้นำไปใช้เชิงพาณิชย์ได้โดยไม่เสียค่าใบอนุญาต หากปฏิบัติตามเงื่อนไข AGPL ทั้งหมดที่เกี่ยวข้อง ใบอนุญาตเชิงพาณิชย์เป็นทางเลือกเพิ่มเติมสำหรับผู้ที่ต้องการสิทธิซึ่ง AGPL ไม่ได้ให้ไว้ เช่น การแจกจ่ายรุ่นกรรมสิทธิ์โดยไม่ต้องเปิดเผยซอร์สตามภาระผูกพันที่ปกติใช้บังคับ ทั้งนี้ต้องมีการให้สิทธิดังกล่าวอย่างชัดแจ้งในข้อตกลงเชิงพาณิชย์ที่ลงนามแล้ว

## การขอใบอนุญาตเชิงพาณิชย์

ติดต่อผ่านช่องทางข้างต้นโดยใช้หัวข้อ **Commercial licence request — LunaV** พร้อมอธิบายสั้น ๆ ว่าจะนำไปใช้อย่างไรและองค์กรต้องการสิทธิใด ราคา ขอบเขต ระยะเวลา การสนับสนุน การอัปเดต และเงื่อนไขอื่นจะหารือและบันทึกไว้ในข้อตกลงเป็นลายลักษณ์อักษรแยกต่างหาก โดยต้องระบุคู่สัญญาและผลงานที่ข้อตกลงครอบคลุม

เอกสารนี้หรือการส่งคำถามไม่ได้ให้สิทธิเชิงพาณิชย์เพิ่มเติมนอกเหนือจาก AGPL ใบอนุญาตเชิงพาณิชย์แยกต่างหากจะมีผลต่อเมื่อคู่สัญญาที่เกี่ยวข้องยอมรับข้อตกลงแล้วเท่านั้น

## การร่วมพัฒนาและความเป็นเจ้าของ

ใบอนุญาตเชิงพาณิชย์แยกต่างหากครอบคลุมได้เฉพาะโค้ดที่ผู้อนุญาตมีสิทธิหรือได้รับอนุญาตให้ให้สิทธินั้น ก่อนรับผลงานจากบุคคลภายนอก เจ้าของโครงการควรกำหนดเงื่อนไขการร่วมพัฒนาให้ชัดเจนและยืนยันว่าเงื่อนไขนั้นรองรับรูปแบบการให้สิทธิสองทางที่ต้องการ โค้ดและ dependencies ของบุคคลที่สามยังอยู่ภายใต้ใบอนุญาตของตนเอง

repository นี้มีเว็บไซต์โครงการ LunaV ไม่ได้รวมซอร์สแอป iPhone หรือไฟล์น้ำหนักโมเดล ข้อตกลงเชิงพาณิชย์ต้องระบุอย่างชัดเจนว่าครอบคลุมซอร์สแอป ทรัพยากร หรือผลงานอื่นใดที่ส่งมอบแยกต่างหาก ประกาศนี้ไม่ได้ให้สิทธิเพิ่มเติมในโมเดลหรือ dependencies ของบุคคลที่สาม

## ข้อสงวน

ไฟล์นี้เป็นประกาศเรื่องการใช้สิทธิของโครงการ ไม่ใช่คำแนะนำทางกฎหมายหรือเอกสารทดแทนสัญญาอนุญาตใช้สิทธิเชิงพาณิชย์ฉบับสมบูรณ์ ควรให้ผู้เชี่ยวชาญตรวจข้อตกลงให้เหมาะกับกรณีของคุณก่อนนำไปใช้
